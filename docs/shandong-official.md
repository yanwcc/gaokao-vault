# 山东官方投档数据

`sdzk_official` 任务直接从山东省教育招生考试院（<https://www.sdzk.cn/>）导入官方 Excel 附件，
作为山东模拟志愿的核心数据。山东 2020 年起实行"专业（类）+ 学校"志愿模式、不分文理，
投档情况表本身就是"专业 + 院校"粒度的最低位次。春季高考（职教高考）的投档表和一分一段表也由同一任务导入，
位次按专业类别各自排名。

```bash
gaokao-vault run-spider sdzk_official                     # 2020 年至今全量
gaokao-vault run-spider sdzk_official --mode incremental  # 近 3 年
```

## 数据来源

| 栏目 | 标题 | 入库 |
|------|------|------|
| 院校投档情况（CID 47） | `山东省YYYY年普通类常规批第N次志愿投档情况表` | `provincial_admission_records` |
| 分段表（CID 49） | `YYYY年夏季高考文化(总)成绩一分一段表` | `score_segments`（科类 `综合`，取"全体"列） |
| 春季高考 · 院校投档情况（BCID 1199，CID 1201） | `山东省YYYY年春季高考本科批/专科批第N次志愿投档情况表` | `provincial_admission_records`（批次 `春季本科批` / `春季专科批`） |
| 春季高考 · 分段表（BCID 1199，CID 1203） | `YYYY年春季高考(成绩)一分一段表` | `score_segments`（科类为专业类别） |
| 分数线（CID 48） | `山东省YYYY年夏季高考各类别分数线`（PDF） | `admission_score_lines`（科类 `综合`，批次 `常规批`） |
| 春季高考 · 分数线（BCID 1199，CID 1202） | `山东省YYYY年春季高考各专业类别录取控制线`（PDF） | `admission_score_lines`（科类为专业类别） |

栏目列表翻页是 ASP.NET 回传，爬虫带页面隐藏字段模拟"下一页"。附件格式逐年漂移（首列空列、
两行表头、2020 年有最低分/计划数、2023 年起第 2/3 次有层次、2026 年起有选考科目要求；
2020 年一分一段表是 HTML 导出的 `.xls`），解析按表头关键字定位列，见 `spiders/sdzk.py`。

## 春季高考

- 从 2023 年起导入。2020–2022 年的春考投档表只到"院校（专业类别）"，没有专业；2020–2021 年还是改革前的
  专业类别（如 `农林果蔬`）。官网没有 2022 年春考一分一段表。
- 30 个专业类别（`现代农艺` … `艺术设计`，官方代码 01–30）预置在 `subject_categories`，`category_type = 'spring'`。
- 投档表每行带专业类别，存入 `provincial_admission_records.subject_category_id`；同一院校的同名专业会在不同
  专业类别下分别招生，代号和位次各不相同。夏季高考的行此列为空。
- 一分一段表按专业类别各自累计，存入 `score_segments.subject_category_id`；夏季高考为 `综合`。
  读 `score_segments` 或 `gaokao_source.score_rank_v` 时必须按科类（`subject_category`）过滤。
- `education_level` 由批次决定：本科批为本科，专科批为专科。

## 批次线：`admission_score_lines`

- 从 2025 年起导入：分数线公告 2025 年起是带文字层的 PDF，用 `pypdf` 取文字；更早的年份是图片，不导入。
  山东按位次投档，模拟志愿只用当年的线判断资格，不需要往年的线。
- 夏季高考只取普通类：`special_name` 为 `特殊类型招生控制线`、`一段线`、`二段线`，批次 `常规批`，科类 `综合`。
  艺术类、体育类和"3+2"资格线不导入。
- 春季高考：`春季本科批` 每个专业类别一条本科录取控制线；专科线全省各类别相同，按类别各存一条到
  `春季专科批`，`special_name` 均为 `录取控制线`。技能拔尖人才本科线不导入。
- 第 2/3 次志愿的填报资格线、录取控制线（图片）不导入。

## `provincial_admission_records`

按官方表格逐行保存，唯一键为 `(province_id, year, batch, admission_round, school_code_raw, major_code_raw)`。

- `school_code_raw` 是山东本省院校代号（如 `A001`），跨年稳定，院校更名时代号不变；
  `school_id` 按校名关联 `schools`，关联不上时为空。
- 专业不强行映射到全国专业目录：大量行是专业类（`计算机类`、`理科试验班类`）。
  `major_name` 为括号前名称，`major_note` 为括号内备注，`program_type` 由备注抽取（如 `专项计划`）。
- `min_rank_raw` 保存非数字位次（如 `前50名`）。

## 往年投档推断：`gaokao_source.provincial_admission_history_v`

当年完整招生计划发布前（每年 6 月下旬），用每个层次第一次投档的历年记录推断"今年大概率仍会招生"的
专业 + 院校：

- 常规批本科取第 1 次志愿，专科取第 2 次志愿：常规批第 1 次只投本科，专科从第 2 次开始；第 2 次里的本科是
  征集余额，不计入。`education_level` 列区分本科和专科。
- 春季本科批、春季专科批各取第 1 次志愿，并按 `subject_category`（专业类别）分开汇总。
- 投档记录的 `education_level` 取官方表里的层次；第 1 次的表没有层次列，取所关联院校的办学层次，
  仍为空的按本科处理。第 2 次的表里有本科院校开设的专科专业，所以不能直接用院校层次覆盖。
- 按 `(批次, 层次, 专业类别, 院校代号, 专业名称, 备注)` 跨年汇总，`min_ranks_by_year` 给出每年最低位次，
  `latest_year` 为最近一次出现的年份，`latest_major_codes` 为最近一年的专业代号。
- 专业代号每年会变，不能用于跨年关联，也不能直接当作下一年的志愿代号。
- 同一年同校出现多个"名称 + 备注"相同但代号不同的专业（分校区、收费标准不同，表中不区分）时，
  保留当年全部位次并标记 `is_ambiguous`，不擅自取其中一个。

!!! warning "局限"
    投档表不含学费、计划数（2021 年起）、单科/体检等限制，也无法反映新增、停招和选科要求变化。
    填报期必须换成当年官方招生计划。
